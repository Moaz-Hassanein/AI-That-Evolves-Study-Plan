# 📚 EvoStudy — An Adaptive Study Planner Powered by Evolutionary Algorithms

EvoStudy is an AI-driven study planning system that evolves personalized study schedules over time using a Genetic Algorithm.
Unlike static timetables or rule-based planners, EvoStudy continuously adapts to user behavior, performance, fatigue, and missed sessions to generate increasingly effective study plans.

The system treats each study plan as a candidate solution and iteratively improves it through selection, crossover, and mutation, guided by real user feedback.

---
🚀 Key Features

- 🧬 Genetic Algorithm–based optimization of study plans
- 🔄 Adaptive feedback loop using user performance, focus, and adherence
- 😵 Fatigue-aware scheduling to avoid burnout
- 🎯 Goal and syllabus coverage optimization
- 📈 Visual comparison of study plans across generations

---

🧠 How It Works

- Generate an initial population of study plans
- Evaluate plans using a fitness function (performance, adherence, fatigue, coverage)
- Evolve plans across generations using genetic operators
- Incorporate daily user feedback to improve future schedules

---

🎯 Use Case
EvoStudy is designed for students who struggle with:

- Overambitious schedules
- Inconsistent study habits
- Burnout and fatigue
- Poor long-term planning
